Features
1. Course Catalog: Browse through a wide variety of courses and tutorials across multiple subjects and categories.
2. Course Enrollment: Users can create accounts, view course details, and enroll in courses.
3. Instructor Profiles: Display detailed profiles of instructors with their expertise and experience.
4. Interactive Tutorials: Access course materials like video tutorials, documents, and quizzes.
5. Progress Tracking: Users can track their progress in the enrolled courses.
6. Admin Dashboard: Manage courses, instructors, students, and track analytics through an easy-to-use admin panel.
Technologies Used
-Python 3.x
-Django 3.x (for backend development)
-SQLite (default database, can be replaced with PostgreSQL)
-HTML5/CSS3 (for frontend design)
-Bootstrap 4 (for responsive design)
-JavaScript (for dynamic content)
-jQuery (for UI interaction)
